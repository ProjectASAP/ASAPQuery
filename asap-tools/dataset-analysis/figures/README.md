# Figures

Generated by `fit_skew.py` from the sample in `../README.md` (the plots land in
`out/` and are copied here). File names are `<dataset>__<query_id>__<kind>__<range>.png`:

- `rank_count` / `rank_value`: log-log rank-frequency of the query's group-by key
  (count- or value-weighted), pooled over all evaluation times, with the lower,
  MLE and upper Zipf θ drawn as reference lines.
- `ccdf`: log-log complementary CDF of a value query's values with the fitted
  power-law tail (from x_min); compare with `tail_class` in
  `../results/skew_summary.csv` (power law vs lognormal is often undecidable).
- `<range>` is `instant`, `1m`, `5m` or `1h`; BOOM series have no range.
